About NTAG 424 DNA tags

NTAG 424 DNA is NXP's secure NFC chip. Each time a phone taps it, the tag adds a fresh encrypted code (a SUN message) to its link. Your server checks that code, so a copied or replayed tag fails verification.

Brands use it to prove products are genuine, to protect warranty registration and to run loyalty programs that cannot be faked. It is hard to buy in small and mid-size quantities in Canada, and we can configure the keys for you before shipping.

Common uses

  • Product authentication for brands
  • Anti-counterfeiting for wine, spirits and cosmetics
  • Warranty and ownership registration
  • Secure loyalty and rewards
  • Tamper-evident seals

Questions about NTAG 424 DNA tags

How does NTAG 424 DNA verification work?

Each tap creates a link containing an encrypted counter and signature. Your server checks the signature and counter, and only accepts each code once.

Do I need my own server?

Yes, you need a verification service. We can configure the tag keys and point the tags at your verification URL.

Can NTAG 424 DNA tags be copied?

The tag's secret key cannot be read out, and each code is only valid once, so a copy will not pass verification.
