About NTAG215 NFC stickers

NTAG215 has 504 bytes of memory, about three and a half times as much as NTAG213. That leaves room for long tracking links, a short vCard, or more than one record on the same tag.

It reads the same way as NTAG213, on any NFC-enabled phone with no app needed, so you can switch between the two without changing anything else.

Common uses

  • Links with long tracking or campaign parameters
  • Short contact cards (vCard)
  • App launch records
  • Multiple records on one tag

Questions about NTAG215 NFC stickers

What's the difference between NTAG213 and NTAG215?

Only the memory. NTAG213 holds 144 bytes and NTAG215 holds 504 bytes. Both read the same way on every NFC phone.

Does NTAG215 work with iPhone?

Yes. iPhone XS and newer read NTAG215 tags in the background without an app.
